---
name: Comment style
description: Preferred inline comment format for this project
type: feedback
---

Write comments as short, lowercase, descriptive verb phrases. No decorators, dashes, or title case.

**Why:** User explicitly prefers `# extracts row` over `# --- Extract ---` style.

**How to apply:** Any time you write an inline or section comment, use plain lowercase verb phrases. e.g. `# finds the header row`, `# groups words by y-coordinate`, `# skips the opening balance row`.
